Öğrenci Takip Otomasyonu

C# Windows Forms ve Microsoft Access kullanılarak geliştirilmiş, öğrencilerin eğitim ve ödeme süreçlerinin takip edilmesini sağlayan masaüstü otomasyon uygulamasıdır.

📌 Proje Hakkında

Bu proje; öğrenci bilgilerinin, derslerin, devamsızlıkların, ödemelerin ve deneme/sınav sonuçlarının tek bir sistem üzerinden yönetilmesini amaçlamaktadır.

Uygulama içerisinde farklı işlemlere kolayca erişilebilmesi için merkezi bir menü yapısı oluşturulmuştur.

🚀 Özellikler

- 👨‍🎓 Öğrenci kayıt ve bilgi yönetimi
- 📚 Ders yönetimi
- 📅 Devamsızlık takibi
- 💳 Ödeme takibi
- 📝 Deneme/sınav takibi
- 📊 Raporlama
- 🏠 Merkezi menü sistemi
- 🗄️ Microsoft Access veritabanı kullanımı

🖥️ Kullanılan Teknolojiler

- C#
- Windows Forms
- .NET
- Microsoft Access
- Visual Studio

 Proje Modülleri

Form| Açıklama
Öğrenci Formu| Öğrenci bilgilerinin eklenmesi ve yönetilmesi
Ders Formu| Ders bilgilerinin yönetilmesi
Devamsızlık Formu| Öğrencilerin devamsızlık bilgilerinin takip edilmesi
Ödeme Formu| Öğrenci ödeme bilgilerinin takip edilmesi
Deneme Formu| Deneme/sınav bilgilerinin yönetilmesi
Rapor Formu| Verilerin raporlanması
Menü Formu| Uygulama içerisindeki modüllere erişim

Veritabanı

Projede verilerin saklanması ve yönetilmesi için Microsoft Access veritabanı kullanılmıştır.

 Projenin Amacı

C# Windows Forms ve veritabanı teknolojileri kullanılarak gerçek bir kullanım senaryosuna yönelik masaüstü otomasyon uygulaması geliştirmek ve öğrenci yönetim süreçlerini tek bir sistem üzerinden kolaylaştırmak.
